# 프론트엔드 UI 및 스타일링 규칙 (Frontend UI & Styling)

## UI 및 시각화 컴포넌트 (UI & Visuals)
- 아이콘 표기에는 `lucide-react`를 활용하세요.
- 데이터 시각화에는 `recharts`를 활용하세요. 차트 데이터는 Recharts가 요구하는 입력 구조에 맞게 올바르게 정제 및 포맷팅되어야 합니다. (참고: 데이터 계산에 대한 메모이제이션 규칙은 성능 가이드라인을 참조하세요).
